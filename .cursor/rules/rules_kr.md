# PromptShelf 규칙

## 목적

PromptShelf는 고품질 AI 프롬프트를 발견하고, 공유하고, 정리하고, 재사용할 수 있는 플랫폼이다.

서비스는 아래 느낌을 가져야 한다:

* 빠름
* 미니멀함
* 실용적임
* 커뮤니티 중심
* 생산성 중심

불필요한 복잡함은 피한다.

---

## 디자인 원칙

* 깔끔하고 현대적인 UI
* 가독성 최우선
* 불필요한 요소 최소화
* 다크모드 온/오프 기능 지원
* 모든 디바이스 반응형 지원
* 장식보다 콘텐츠 중심

충분한 여백과 명확한 타이포그래피를 사용한다.

---

## 핵심 UX 규칙

프롬프트 카드는 반드시 아래 기능을 지원해야 한다:

* 원탭 복사
* 모바일에서 꾹 눌러 복사
* 복사 완료 시 즉각적인 피드백 제공
* 부드럽고 빠른 인터랙션

프롬프트 복사는 최대한 자연스럽고 편해야 한다.

---

## 개발 규칙

* TypeScript만 사용
* 함수형 컴포넌트 사용
* 가능하면 서버 사이드 렌더링 우선
* 컴포넌트는 재사용 가능하게 설계
* 중복 로직 금지
* 의미 있는 네이밍 사용
* 파일은 작고 유지보수 가능하게 유지

---

## 코드 스타일

* Promise 체인 대신 async/await 사용
* early return 우선
* 깊은 중첩 조건문 지양
* 코드 자체로 읽히게 작성
* 주석은 꼭 필요한 경우만 사용

---

## UI/UX 규칙

* 모든 동작은 즉각적으로 느껴져야 한다
* 사용자 흐름은 단순해야 한다
* 클릭 수를 최대한 줄인다
* 프롬프트 탐색과 발견 경험 최적화
* 모바일 사용성 최우선

---

## 프롬프트 시스템

프롬프트는 아래 요소를 지원해야 한다:

* 제목
* 설명
* 태그
* 카테고리
* 복사 버튼
* 즐겨찾기
* 추천 기능
* 작성자 표시

---

## 커뮤니티 기능

아래 행동을 장려한다:

* 공유
* 리믹스
* 저장
* 평가
* 탐색

스팸성 기능 구조는 지양한다.

---

## SEO 규칙

* 모든 페이지 SEO 최적화
* 시맨틱 HTML 사용
* 깔끔한 URL 구조 유지
* 프롬프트 메타데이터 추가
* 페이지 속도 적극 최적화

---

## 성능 규칙

* 무거운 컴포넌트는 lazy loading 사용
* 이미지 최적화
* 클라이언트 JavaScript 최소화
* 가능하면 정적 생성 우선
